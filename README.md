# AgriEvidence

Which agricultural sites in Akamkpa Local Government Area, Cross River State, overlap with or sit within 1 kilometer of protected forest reserves and experienced forest cover loss from 2020 to present?

Built for twelve months with GeoDev Lab Africa, Cohort One.
